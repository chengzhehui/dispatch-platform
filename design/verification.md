## 有意调整

- 概念图中的写实炼厂替换为用户指定的真实阿联酋模型；保留其几何和原始材质，不伪造设备或改色。概念图仅作为界面结构、配色与操作层级参考，不能声称真实模型与插画逐像素一致。

- 全景优先完整包围单元及预备区；可通过“预备区”、工区定位和滚轮查看细节。

- 文案核对：保留“派工可视化平台”“阿联酋项目”“今日焊工”“设置人数”“单元加载”“选中焊工”“全景”“预备区”“工区网格”“工区尺寸”“工区人员统计”。“派工高度”改为含实际高度的“派工楼层”；“预备区/区外”明确坐标统计口径。新增文案均对应具体操作或状态。

## 程序化焊接与真实 EP3D 焊缝绑定

复用现有骨骼，叠加双臂、手腕往复和低位屈膝，附加简易焊枪、弧光与火花，区分待机、前往焊缝和持续焊接。复用 three-demo 的 batch-face 拾取、componentId 属性映射及同节点多个几何联合高亮逻辑；按 EP3D 对象 ID 而非焊缝显示名绑定，避免同名焊缝误合并。源 GLB 未修改。

独立项目内包含完整属性索引及按需属性分片，约 32 MB。213 单元共 70,820 个构件、19,333 个焊缝节点，其中 19,327 个可定位；源数据未提供其他四个单元的 EP3D 属性，界面明确提示。设计分支保持概览加载，EP3D 随距离细化。定位焊缝时隐藏设计模型，可用顶部按钮恢复。

验证：

- `npm test`：16 项通过，包括真实 batch-face 提取、多几何高亮、一次坐标变换、独立数据完整性、同名节点保留、单人占用、恢复校验和循环姿态。
- `smoke-welding.mjs`：真实鼠标点击 213 单元 FW-46 焊缝，三个子几何共同高亮、按需显示 EP3D 原属性、工人前往后循环焊接、重复绑定不清空计时、第二人不能抢占、暂停与刷新恢复、手动接管与停止释放均通过。

- `npm run check:models`：10,413 个本地模型文件及本地带骨骼人物资源完整；`npm run build` 成功，完整模型与 EP3D 属性进入 dist。仍有约 1 MB 主包体积提示，不影响构建。
